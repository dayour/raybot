## Step 21 — Monitor is now Analytics

In the new Coral **agent workspace**, the top navigation reads: Overview, Knowledge, Tools, Agents,
Topics, Activity, Evaluation, **Analytics**, Channels.

The runtime tab is **Analytics**, at `/bots/{botId}/analytics/summary`. The legacy
`/bots/{botId}/monitor` route **bounces back to `/overview`**.

The in-canvas designer still exposes a **Monitor** tab, with the older card layout. Both names
coexist, and which one you see depends on your entry point.

## Step 22 — Evaluate, new experience

The flow has been reorganised since Phase 5.

**Data source** offers CSV upload (5 MB maximum), **Quick conversation set** — which auto-generates
ten cases from the agent's description, instructions, and topics — and *Write your own*.

**Review test cases** shows each case with a Total messages count, alongside a **Configure test set**
panel holding Name, **Test method** (General quality), and **User profile → Manage**.

The user-profile control is new and consequential: it picks an authenticated account so that
tool-using agents are tested with real connections rather than anonymous ones.

A running evaluation shows an **Evaluation summary** panel — Duration, Test cases, Test Set, Data
type, User profile, Tested by — while it reports *"Preparing test cases…"*.

:::danger Runs hang indefinitely on IQ and tool agents
Evaluations against agents that use Microsoft IQ or tools sit in **Running** forever. This is
consistent with the Phase 5 evaluation-runtime gap and confirms it was not specific to Raybot or to
the original tenant.

Do not block on evaluation completion for these agents.
:::

## Step 23 — Workflows designer

**Entry path.** Left rail **Flows** icon, then the **Workflows** list — empty, showing *0 items* with
a **New Workflow** split button — then **Create your first workflow**. The canvas opens at
`/flows/new/canvas` with a single **Start** node, defaulting to a **Manual** trigger.

Designer module: `s01-workflow-designer/22.19.1`.

### Trigger types

Four, from the Start node configuration dropdown:

| Trigger | Behaviour |
| --- | --- |
| Manual | Run on demand |
| Recurrence | Run on a schedule |

Two behaviours apply across all of them:

- **Every placed node** shows a **"Setup needed"** badge plus a health-center banner — *"N new
  issue(s) detected"* with Open health center and Dismiss — and a per-field validation toast until
  configured.
- **Container nodes** (Loop, Scope) render as dashed rectangles with a nested plus for inner steps.

### The reliable per-node capture pattern

Capturing thirteen node types one at a time needs a deterministic reset, because the canvas
accumulates state and element references go stale.

```js
// 1. Reset the canvas to just Start.
await page.goto('.../flows/new/canvas');
await page.waitForTimeout(3500);

// 2. Open the add dialog.
await page.getByRole('button', { name: 'Add a step after Start' }).first().click();
await page.waitForTimeout(1500);

// 3. Place the node.
await page.getByRole('button', { name: 'Select action: <NodeName>' }).click();
await page.waitForTimeout(2500);

// 4. Capture to captures-2026-06-17/raw/NN-node-<name>.png
```

:::warning References go stale on every snapshot
Element refs change with each snapshot. Use **role and text locators** through `browser_run_code`,
never stored refs.

Clicking an agent name in the list also opens a **new browser tab** at index 1. Follow it with
`browser_tabs select index:1` or subsequent actions target the wrong page.
:::

## What Phase 7 establishes

1. **The runtime is renaming surfaces underneath stable routes.** Monitor became Analytics, the old
   route redirects, and both names still appear depending on entry point. Automation keyed on tab
   labels will break.
2. **The evaluation gap is not tenant-specific.** It reproduced in a second tenant, on different
   agents, six weeks later.
3. **Workflows is a full orchestration designer**, with branching, looping, scoping, human review,
   and agent invocation as first-class nodes.
4. **Validation is aggressive and immediate.** Every placed node is invalid until configured, and
   says so three separate ways.
5. **Deterministic reset beats incremental capture.** Navigating to a fresh canvas per node was the
   only reliable way to capture thirteen configuration panels.
