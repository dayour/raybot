Every value on this page is read out of the compiled `@raybot/object-model` package at build time.
None of it is transcribed.

## Why this page exists

A documentation site that merely *describes* a type package will drift from it. The description is
prose; the package is code; nothing connects them, so a renamed export leaves the prose quietly
wrong.

This site imports the package instead. The `ModelValue` component holds a typed table of model
exports, so:

- **Renaming or deleting an export** breaks `npm run typecheck`, which CI runs on every push.
- **Referencing an unknown key** throws during static site generation, which fails the build.

Drift becomes a build error rather than slow rot. That is the entire justification for building the
package rather than leaving it as loose source — see
[the build decision](#the-build-decision) below.

## The build decision

Three options were on the table for the package.

| Option | Verdict |
| --- | --- |
| **Source-only** | Rejected. Simplest to set up, but nothing stops the docs and the types from diverging. |
| **Built and imported** | Chosen. `tsc` emits `dist/` with declarations; the site imports from it; drift fails the build. |
| **Published to npm** | Rejected. There are no external consumers, so a release process would have nothing on the other end of it. |

The build is wired so it cannot be skipped. The root `prebuild` and `pretypecheck` scripts each build
the package first, so `npm run build` and `npm run typecheck` are both self-sufficient from a clean
checkout — including in CI, which runs them in that order.

## What this does not prove

Importing the package proves the site and the types agree. It does **not** prove either one matches
the live product. That guarantee comes from a different mechanism: every constant traces to a
captured screenshot, a recorded network request, or a DOM audit row, and the
[confidence model](./index.md#the-confidence-primitive) records how strongly each fact is supported.

A value can be perfectly consistent across the package, the schemas, and this page while still being
stale relative to Coral, which ships continuously. The
[re-audit phase](../runbook/phase-7-reaudit.mdx) exists precisely because that happened — Monitor was
renamed Analytics between the original build and the audit.
