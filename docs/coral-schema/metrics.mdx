## How each number was produced

| Metric | Method |
| --- | --- |
| Surfaces | One DOM dump per distinct UI state, driven manually through the UI |
| Elements | Every node in every dump, deduplicated within a surface |
| Interactive | Computed from tag, role, `tabindex`, and `contenteditable` — never asserted |
| With test id | Presence of a `data-testid` attribute, independent of interactivity |
| Unique test ids | Distinct `data-testid` values across all surfaces |
| Label gaps | Interactive elements where the label heuristic returned nothing |
| Shared test ids | Test ids where `surfaceCount` exceeds one |
| Requests observed | All network traffic captured during the sessions |
| Functional | Requests remaining after removing static assets, telemetry, and duplicates |
| Endpoints | Functional requests collapsed by method plus host plus normalized path |

## The three overlapping populations

```text
1,627  elements
1,115  interactive
  983  with test id
```

`1,115 + 983` exceeds `1,627`. The sets overlap but neither contains the other: there are interactive
elements with no test id, and test-id-bearing elements that are inert.

Treating "has a test id" as a proxy for "is interactive" produces wrong numbers in both directions.
See [honesty note 1](./confidence.md).

## Request status distribution

| Status | Count | Reading |
| --- | --- | --- |
| 200 | 555 | Success |
| 404 | 35 | Mostly optional-resource probes |
| 500 | 9 | Includes the Teams `msteams/app/status` failures |
| 405 | 6 | Method not allowed — probe artifacts |
| 412 | 3 | Precondition failed — ETag conflicts |
| FAILED | 3 | Network-level failure, no response |

555 + 35 + 9 + 6 + 3 + 3 = 611. The distribution accounts for every functional request.

The 9 HTTP 500s are not noise. Some of them are the Teams channel status failure that blocked
[Phase 6](../runbook/phase-6-teams.mdx) outright. A status distribution that silently dropped them
would have hidden the single hardest blocker in the build.

## Numbers deliberately not reported

**Coverage percentage.** There is no denominator. Sixteen surfaces were captured; the total number of
surfaces in Coral is unknown. Any percentage would be invented.

**Defect counts.** The 228 label gaps are a lower bound on investigation, not defects. See
[label gaps](./label-gaps.mdx).

**Performance timings.** Captured incidentally, not measured under controlled conditions. Reporting
them would imply a rigor the method did not have.

## Counts that disagree elsewhere in the source repo

Three different gallery counts exist across the source repository: 67, 41, and 38. All three are
correct for their own scope, and none is a superset of the others.

| Count | Scope |
| --- | --- |
| 67 | Every capture in `gallery.json` |
| 41 | Curated set in `screenshot-map.md` |
| 38 | Images verified HTTP 200 in the `darbot-validation` run |

The disagreement is recorded in the [errata](../reference/errata.md) rather than resolved by picking
one, because each number answers a different question and silently unifying them would lose
information.
